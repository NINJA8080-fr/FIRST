# 💛 مفاجأة Venuus - موقع سري من Riven

موقع ويب خاص ومفاجأة لـ **Venuus** من **Riven**، مصمم بتجربة بصرية وعاطفية "هرباااانة" مع حماية بكود سري.

## 🎯 المميزات

### 🔐 الأمان والخصوصية
- صفحة دخول محمية بكود سري (VRM1)
- التحقق من الكود على السيرفر (ليس في الكلاينت)
- الموقع مخفي من محركات البحث (noindex, nofollow)

### ✨ التجربة البصرية
- **صفحة الدخول**: أنيميشن مفتاح دوار مع تأثيرات ضوئية
- **Hero Section**: اسم Venuus بخط handwritten مع تأثير نبض ضوئي + confetti
- **Timeline**: شريط زمني للحظات المشتركة مع modals تفاعلية
- **غرفة المفاجآت**: 3 مفاجآت (رسالة صوتية، لعبة، رسالة typewriter)
- **هدية رقمية**: wallpaper قابل للتحميل مع تأثير confetti
- **كتاب الزوار**: نموذج لإضافة رسائل مع تخزين
- **شاشة وداع**: رسالة ختامية مع Easter Egg مخفي

### 🎮 التفاعلات الخاصة
- موسيقى خلفية اختيارية مع زر تشغيل/إيقاف
- Easter Egg: اضغط 3 مرات على اسم Riven
- تأثيرات صوتية وبصرية عند كل تفاعل
- Micro-interactions مع hover وclick

## 🛠️ التقنيات المستخدمة

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion
- **Effects**: Canvas Confetti
- **Language**: TypeScript
- **Fonts**: Cairo (عربي) + Dancing Script (handwritten)

## 📦 التثبيت والتشغيل

### المتطلبات
- Node.js 18+ أو أحدث
- pnpm (أو npm/yarn)

### خطوات التثبيت

1. **استنساخ المشروع** (إذا كان في Git):
```bash
git clone <repository-url>
cd venuus-surprise
```

2. **تثبيت المكتبات**:
```bash
pnpm install
# أو
npm install
```

3. **إضافة الأصول (Assets)**:

#### الصور (مطلوبة):
ضع الصور التالية في `/public/images/`:
- `moment1.jpg` - صورة اللحظة الأولى
- `moment2.jpg` - صورة اللحظة الثانية
- `moment3.jpg` - صورة اللحظة الثالثة
- `gift-preview.jpg` - معاينة الهدية (اختياري)

#### الصوتيات (اختيارية):
ضع الملفات الصوتية في `/public/audio/`:
- `message.mp3` - الرسالة الصوتية من Riven
- `background-music.mp3` - الموسيقى الخلفية

#### الهدية الرقمية:
ضع الـ wallpaper في `/public/downloads/`:
- `venuus-wallpaper.png` - الخلفية المخصصة

4. **تشغيل المشروع في وضع التطوير**:
```bash
pnpm dev
# أو
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

5. **بناء المشروع للإنتاج**:
```bash
pnpm build
# أو
npm run build
```

## 🎨 التخصيص

### تغيير الكود السري
افتح `/app/api/verify/route.ts` وغيّر:
```typescript
const SECRET_CODE = 'VRM1'; // غيّر هنا
```

### تعديل المحتوى
افتح `/lib/data.ts` لتعديل:
- بيانات Timeline (التواريخ، العناوين، الأوصاف)
- محتوى المفاجآت (الرسالة الخاصة)
- معلومات الهدية الرقمية

### تغيير الألوان
الألوان الرئيسية في Tailwind:
- `yellow-400` / `amber-600` - الذهبي
- `slate-900` / `slate-800` - الخلفية الداكنة
- `purple-900` - اللون البنفسجي

يمكنك تعديلها في ملفات المكونات أو في `tailwind.config.ts`.

### تعديل الخطوط
افتح `/app/layout.tsx` لتغيير الخطوط من Google Fonts.

## 🚀 النشر على Vercel

1. **إنشاء حساب على Vercel** (إذا لم يكن لديك):
   - اذهب إلى [vercel.com](https://vercel.com)
   - سجّل الدخول بحساب GitHub

2. **رفع المشروع**:
   - اضغط على "New Project"
   - اختر المشروع من GitHub (أو ارفع المجلد مباشرة)
   - Vercel سيكتشف Next.js تلقائياً

3. **الإعدادات**:
   - Framework Preset: Next.js
   - Build Command: `pnpm build` (أو `npm run build`)
   - Output Directory: `.next`

4. **النشر**:
   - اضغط "Deploy"
   - انتظر حتى ينتهي البناء
   - ستحصل على رابط مثل: `https://venuus-surprise.vercel.app`

### نشر على منصات أخرى

#### Netlify:
```bash
pnpm build
# ثم ارفع مجلد .next
```

#### استضافة خاصة:
```bash
pnpm build
pnpm start
# سيعمل على المنفذ 3000
```

## 🔧 استكشاف الأخطاء

### الصور لا تظهر
- تأكد من وضع الصور في `/public/images/`
- تأكد من أسماء الملفات صحيحة
- تحقق من `/lib/data.ts` للتأكد من المسارات

### الصوت لا يعمل
- تأكد من وضع ملفات MP3 في `/public/audio/`
- بعض المتصفحات تمنع التشغيل التلقائي
- اضغط على زر التشغيل يدوياً

### الرسائل لا تُحفظ
- في وضع التطوير، الرسائل تُحفظ في `/data/messages.json`
- على Vercel، استخدم قاعدة بيانات خارجية (Firebase/Supabase)

### خطأ في البناء
```bash
# امسح الـ cache وأعد البناء
rm -rf .next
pnpm build
```
